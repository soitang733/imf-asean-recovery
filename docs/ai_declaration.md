# AI use declaration

AI tools supported interpretation of the assignment, Python scaffolding, debugging, visualization design and wording. The pipeline itself retrieves observations from the IMF SDMX API and calculates all reported metrics from saved data. Team members remain responsible for verifying indicator definitions, units, coverage, formulas, figures, interpretations and citations. Every member should be able to explain the SDMX key, cleaning steps, derived features, missing-data policy, outlier rule, cluster selection and the limits of descriptive analysis.
